# 用户指南

Quality MS 将您的质量记录集中在一处：供应商证书、检验、校准、不合格、纠正措施、受控文件和内部审核。各部分环环相扣，您可以追溯任何批次，从其到货时附带的证书，一直到解决问题的纠正措施。

## 入门

### 登录与账户

使用管理员提供的电子邮件和密码登录。在 **设置**（侧边栏底部的用户菜单中）里，您可以修改姓名、电子邮件和密码，并启用双重身份验证或通行密钥。

### 语言

在用户菜单中选择 **English**、**Bahasa Melayu** 或 **中文**。您的选择会保存在账户中，在任何设备上都会生效。

### 界面导航

侧边栏按工作分组：

- **来料**：证书、批次查询、供应商和物料。
- **质量**：检验、检验计划、零件和量具。
- **改进**：不合格、CAPA、内部审核和文件。
- **系统管理**：用户（仅限管理员）。

您只能看到您的角色允许访问的页面。

### 列表

所有列表的用法都相同。在搜索框中输入内容进行筛选，使用下拉框和状态标签缩小范围，点击列标题排序，并选择每页显示的行数。地址栏会保留您的搜索和筛选条件，因此可以将筛选后的列表加入书签或分享给他人。**导出**会按当前筛选条件将列表下载为可在 Excel 中打开的 CSV 文件。

### 必填字段

字段名后的红色 **\*** 表示该字段必须填写。保存时如有遗漏或错误，提示信息会显示在该字段下方。

## 角色

| 角色 | 职责 |
|---|---|
| 管理员 | 全部功能，包括管理用户和角色。 |
| 质量经理 | 审批与决策：验证证书，批准计划和文件，记录校准，批准 NCR 处置，关闭 NCR 和 CAPA。 |
| 检验员 | 记录工作：证书及其结果、检验、NCR 和 CAPA 措施。 |
| 审核员 | 查看全部内容并执行内部审核。 |
| 查看者 | 查看全部内容。 |

管理员可以在**系统管理 → 角色**中添加**自定义角色**，并精确勾选每个角色可执行的操作。上述内置角色固定不变。

## 仪表板

仪表板显示今天需要关注的事项：未关闭的 NCR、逾期的 CAPA、校准到期或逾期的量具、待验证的证书、进行中的检验、待评审的文件，以及要求您阅读的文件。点击数字即可打开对应列表。

数字下方：

- **按来源统计的不合格**（近 90 天），按数量从多到少排列。解决排名前一两位的来源，通常就能消除大部分问题。
- **ISO 9001 证据** 列出每个条款及覆盖该条款的文件和记录。标记为 **差距** 的条款两者皆无；请在审核前查看。

## 来料

### 供应商

为每个供应商添加代码和名称。供应商获批后，勾选 **合格供应商** 并填写批准日期。未获批供应商的证书无法验证。

列表还显示每个供应商的表现：其证书的接受比例，以及过去 12 个月内针对该供应商开立的 NCR 数量。

### 物料与规格限值

物料是指按规格采购的东西，例如 *符合 EN 10025-2 的 S355JR 钢* 或 *PA66-GF30 树脂*。打开物料即可添加 **规格限值**：每个属性一行（C、Yield、Moisture…），填写最小值、最大值或两者。恰好等于限值的数值判为合格。

如果限值随尺寸变化（例如钢材屈服强度随板厚变化），请在物料上填写 **尺寸依据**，然后为每条限值设置尺寸范围。同一属性的范围不得重叠。

### 证书

物料到货时，添加其证书：

1. 进入 **证书**，选择 **添加证书**。选择供应商，填写证书编号、类型和签发日期，并附上 PDF 或扫描件。
2. 在证书页面上，添加每个 **批次**（炉号、批号或日期代码）及其物料、尺寸和数量。
3. 为每个批次选择 **录入结果**，从证书上抄录数值。证书未报告的数值请留空。

页面会将每个结果与物料的限值进行比对，并列出所有阻碍验证的问题：超出限值的数值、缺少的结果、未获批的供应商，或缺少第三方检验员的 3.2 证书。

- **EN 10204 2.2、3.1、3.2 和分析证书** 报告检测结果，因此每个设有限值的属性都需要结果。
- **EN 10204 2.1 和符合性证书** 仅声明符合性；需要录入批次，但不需要结果。

随后由质量经理选择 **验证**（核对清单全部通过时）或填写原因后 **拒收**。两者都需要电子签名。被拒收的证书会自动开立 NCR。已作出决定的证书不能再修改。

### 自动读取证书文件

如果管理员已启用该功能，**从文件读取** 会读取所附的 PDF 或扫描件，并为您填写批次和结果。在您核对之前不会保存任何内容：

1. 选择 **从文件读取**，等待几秒钟。
2. 将每个数值与证书比对，更正任何错误。阅读备注，其中会指出不清楚的地方。
3. 为新批次选择物料，然后选择 **应用结果**。

验证证书之前，务必将数值与证书核对。

### 批次查询

输入炉号、批号、证书或供应商，即可查找批次及其到货时附带的证书。

## 校准

### 量具

每台测量仪器都是一个量具，带有代码、校准周期，最好还有负责人。其状态根据到期日期自动得出：

| 状态 | 含义 | 能否使用？ |
|---|---|---|
| 已校准 | 距到期日超过 14 天 | 能 |
| 到期 | 14 天内到期 | 能，直到到期日 |
| 逾期 | 已过到期日，或从未校准 | 否 |
| 停用 | 校准不合格或已停止使用 | 否 |
| 已报废 | 不再使用 | 否 |

量具到期或逾期时，量具负责人每天早上会收到提醒邮件。

### 记录校准

打开量具，选择 **记录校准**。填写日期、校准人和结果，并附上校准证书。

- **合格**：设置下次到期日，量具恢复使用。
- **调整后合格**：同上；请说明发现的问题及调整后的状态。
- **不合格**：量具停用，并开立 NCR。

校准记录不能编辑。如需更正，请记录一次新的校准。

### 量具校准不合格时

量具页面会列出 **可疑检验**：自上次合格校准以来使用过该量具的所有检验。请逐一复查，其结果可能有误。量具再次校准合格后，该列表会清空。

## 检验

### 零件

添加您生产的零件，填写零件号、图纸版本，以及（如已知）所用物料。

### 检验计划

计划列出某个零件或采购物料在某一阶段（来料、过程中或最终）需要检查的项目。

1. 选择 **添加计划**，选择零件或物料、阶段并填写标题。
2. 添加 **特性**：带限值的测量值（例如 9.95 至 10.05 mm），或 OK / 不 OK 检查。设置样本数量，并标记关键特性。
3. 质量经理以电子签名批准该计划。

已批准的计划会被锁定，使以往的检验保留其所用的确切计划。如需更改，请选择 **新版本**；新版本批准后，旧版本即废止。

### 执行检验

1. 选择 **开始检验**，选择已批准的计划；如为来料检验，还需选择批次（仅提供来自已验证且未过期证书的批次）。
2. 录入每个读数。测量值需要选择所用量具；仅提供处于校准有效期内的量具。
3. 边做边 **保存读数**。全部录入后，选择 **完成检验** 并签名。

如有任何读数超出规格，检验即判为不合格，并自动开立 NCR。关键特性不合格时，该 NCR 为严重级别。

## 不合格（NCR）

当检验不合格、证书被拒收、校准不合格或内部审核发现不符合项时，NCR 会自动以草稿形式开立。客户投诉、供应商问题及其他发现可通过 **添加 NCR** 录入。

1. **草稿**：核对详细信息并描述问题，然后选择 **开立 NCR**。误开的草稿可填写原因后取消。
2. **已开立**：决定受影响物料的处理方式（让步接收、返工、返修、报废或退回供应商）并保存处置。"让步接收"需要说明理由。
3. 质量经理以电子签名 **批准处置**。
4. 质量经理 **关闭** NCR。关联的 CAPA 仍未关闭时，NCR 不能关闭。

如果需要解决的是根本原因，而不仅仅是这批物料，请选择 **启动 CAPA**。使用 **打印** 生成可打印的报告；浏览器可将其另存为 PDF。

## 纠正措施（CAPA、8D）

CAPA 按八个步骤推进：

| 阶段 | 进入下一阶段前需填写 |
|---|---|
| 已开立 | D1 团队、D2 问题描述 |
| 调查中 | D3 围堵措施、D4 根本原因、D5 选定的纠正措施 |
| 实施中 | D6 实施，并勾选所有已完成的措施 |
| 验证中 | 有效性检查、D7 预防再发生、D8 关闭与表彰 |
| 已关闭 | 无需再填写；CAPA 已锁定 |

- 添加 **措施**，指定负责人和截止日期，完成后勾选。
- 如果同一问题反复出现，可关联更多 NCR。
- 在 D7 中，**更改受控文件** 会为需要修改的程序创建新的草稿版本，并关联回该 CAPA。
- 质量经理验证有效性（"问题没有再出现"）并关闭 CAPA，两者都需要电子签名。

**8D 报告** 提供可打印版本。

## 文件

受控文件（方针、程序、作业指导书、表单）位于 **文件** 下。

1. **添加文件** 会以草稿版本 A 创建文件。上传文件（PDF、Word、Excel 或扫描件）并说明变更内容。
2. **送审**。
3. 由作者以外的人以电子签名 **批准**。文件立即生效，并取代上一版本。
4. 选择必须阅读该文件的人员。他们会在 **我的阅读清单** 中看到该文件，阅读后进行确认。

每份文件都有评审周期。评审到期时，文件负责人会收到提醒；如无需更改，选择 **确认评审**；如需更改，选择 **新版本**。

为文件标注其覆盖的 ISO 9001 条款；仪表板会使用这些标签。

## 内部审核

1. **安排审核**：标题、范围、主审核员、日期和涉及的 ISO 条款。
2. 当天 **开始审核**。
3. 记录 **发现项**：严重或轻微不符合项、观察项和改进机会。每个不符合项会立即开立 NCR。发现项记录后不能更改。
4. 撰写总结并 **完成审核**。

## 电子签名

批准、验证、拒收、关闭和检验签核时，系统会再次要求输入密码。您的姓名、时间和签署内容会随记录保存并显示，且不能更改或删除。切勿与他人共用密码；以您名义的签名即表示该决定由您作出。

## 审计追踪

对质量记录的每次更改都会记录操作人、时间以及更改前后的数值。任何人都不能编辑或删除该日志。每个记录页面底部都会显示其**历史记录**。对审核重要的记录（校准、发现项、签名）同样不能删除；只能通过添加新记录进行更正。

## 常见问题

**为什么我看不到某个页面或按钮？** 您的角色不包含该权限。请联系管理员。

**为什么"验证"按钮是灰色的？** 证书页面上的核对清单会说明还缺少什么。

**为什么我无法选择量具？** 仅提供处于校准有效期内的量具。请在 **量具** 下查看该量具的状态。

**为什么我无法修改已批准的计划或已验证的证书？** 已批准和已作出决定的记录会被锁定，以确保历史记录可信。请创建新版本，或开立 NCR。
